Zero-Database: Simply drop your photo folder into ./photos and run.



Auto-Generated Thumbnails: Python/Pillow scans high-res images on startup, extracts EXIF/dimensions, and generates optimized thumbnails automatically.



Lightweight \& Fast: Runs on Alpine Linux with minimal RAM and resource usage.



Responsive Lightbox: Smooth mobile-friendly photo viewing powered by PhotoSwipe v5.



Multi-Architecture: Ready-to-use Docker images supporting both amd64 and arm64 (Synology, Raspberry Pi, cloud VPS).
